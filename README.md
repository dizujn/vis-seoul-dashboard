# 서울시 자치구별 상권 분석 대시보드

서울시 25개 자치구의 상권이 시간에 따라 어떻게 변해 왔고, 유동인구·매출·활동 시간대에서
자치구마다 어떤 차이를 보이는지 살펴보는 Streamlit 대시보드입니다.

- 배포 URL: (배포 후 입력)
- 분석 대상: 서울시 25개 자치구
- 분석 기간: 2021년 1분기 ~ 2026년 2분기 (22개 분기)

## 실행

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 대시보드 구성

| 컨셉 | 질문 | 주요 차트 |
|---|---|---|
| ① 자치구별 상권 변화 | 자치구별 상권의 규모와 활력은 시간에 따라 어떻게 변화했는가? | 지도 클릭으로 자치구 선택(최대 5개), 점포 수·개업률·폐업률·추정매출액 시계열 |
| ② 유동인구 × 매출 관계 | 유동인구가 많은 자치구일수록 매출도 높은가? | 산점도 + 회귀선, 자치구별 평균 회귀 잔차, 기준 분기 = 100 지수 추이 |
| ③ 시간대·요일 패턴 | 자치구마다 상권 활동이 집중되는 시간대와 요일은 어떻게 다른가? | 시간대별·요일별 유동인구·추정매출액 구성비(또는 절대값), 시간대는 구간 합계/1시간당 선택 |

①·③에는 선택과 관계없이 **전체 자치구 평균**이 항상 함께 표시됩니다.

| 소득·소비(지출) | 서울시 상권분석서비스 (서울 열린데이터광장) | 자치구 × 분기 |

※ 소득·소비(지출) 데이터는 `data.csv`에 결합되어 있으나 현재 대시보드에서는 사용하지 않습니다.

## 집계·처리 기준

**자치구 × 분기 테이블 (`data.csv`, 550행 × 68열)**
- 점포·추정매출은 업종 단위 원본을 자치구로 합산했습니다.
- 개업률·폐업률 = 자치구 합계 개업(폐업) 점포 수 ÷ 점포 수 × 100으로 재계산했습니다. 업종별 비율의 평균이 아닙니다.
- 총추정매출액 = 원본 `당월_매출_금액`의 업종 합계(분기 기준값)입니다.
- 점포 수는 100개 업종, 추정매출은 63개 업종 기준입니다(37개 업종은 매출 데이터 없음).
- 면적은 서울시 행정구역(구별) 통계의 자치구 면적을 사용했습니다. 경계 SHP에서 계산한 면적과의 차이는 ±0.35% 이내입니다.
- 키(자치구·분기) 1:1 결합, 결측·중복 없음을 확인했습니다. 시간대·요일별 합과 총량의 차이는 반올림 수준입니다.

**자치구 경계 (`seoul_gu.geojson`)**
- 전국 250개 시군구 중 서울(코드 11로 시작) 25개를 추출했습니다.
- 원본 SHP에 좌표계 파일(.prj)이 없어 좌표값으로 EPSG:5179(UTM-K)로 판단했고, 면적 통계와의 일치로 검증했습니다.
- WGS84로 변환하고 지도 표시용으로 경량화(Douglas-Peucker 5m)했습니다.

**전체 자치구 평균**
- 분기마다 25개 자치구 값을 단순 평균한 값입니다. 서울 전체 합계로 계산한 비율(예: 서울 전체 개업 점포 ÷ 전체 점포)과는 다릅니다.
- ③의 구성비 평균은 각 자치구 구성비의 평균이라 합이 100%입니다.

**시간대 환산 (③)**
- 원본 시간대 구간 길이가 00–06시 6시간, 06–11시 5시간, 11–14시·14–17시·21–24시 3시간, 17–21시 4시간으로 서로 다릅니다.
- 시간대 그래프마다 '구간 합계'와 '1시간당'(구간 값 ÷ 구간 길이)을 각각 선택할 수 있습니다. 1시간당 구성비의 균등 분포 기준은 100 ÷ 24 = 4.17%/시간입니다.

**회귀분석 (②)**
- 전체 기간의 550개 관측치(25개 자치구 × 22개 분기)를 하나의 단순 선형회귀로 분석합니다(X = 유동인구, Y = 추정매출액).
- 같은 자치구가 반복 관측되어 관측치가 독립이 아니므로, 기울기 유의확률은 자치구별 군집 표준오차(자유도 24)로 계산합니다.
- 자치구별 잔차는 22개 분기 잔차의 평균으로 제시하고, 분기별 최소~최대 범위를 함께 표시합니다.
- 회귀 결과는 연관성을 나타내며 인과관계를 의미하지 않습니다.

## 파일

| 파일 | 내용 |
|---|---|
| `app.py` | 대시보드 |
| `data.csv` | 자치구 × 분기 통합 테이블 |
| `data_columns.csv` | 컬럼별 출처(유동인구/점포/추정매출/소득소비/면적표) |
| `seoul_gu.geojson` | 서울 25개 자치구 경계 (WGS84) |
| `processing/` | `data.csv`와 경계 파일을 만든 처리 스크립트 |
| `.streamlit/config.toml` | 테마 설정 |

## 재생성

원본 파일을 준비한 뒤 실행합니다.

```bash
python processing/process_csv.py 유동인구.csv 점포.csv 추정매출.csv 소득소비.csv seoul_district_area.csv .
python processing/process_spatial.py sig.shp sig.shx sig.dbf seoul_district_area.csv .
```

`process_spatial.py`는 `spatial/` 폴더에 GeoJSON과 서울만 추출한 SHP(EPSG:5179)를 만듭니다.
